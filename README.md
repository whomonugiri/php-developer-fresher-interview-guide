# PHP Developer Fresher Interview Guide

Code and learning material for the Dev Ninja interview series. Open each part's folder to follow its questions.

| Part | Topic | Material |
| --- | --- | --- |
| 1 | PHP fundamentals | Individual PHP question files |
| 2 | Arrays, strings and forms | Individual PHP question files and form support files |
| 3 | MySQL, PDO and mySQLi | Visual question slides |
| 4 | Sessions, cookies and security | [30-question guide and runnable examples](04%20-%20Sessions%2CCookies%20%26%20Security/README.md) |
| 5 | OOP in PHP | [Guide and examples](05%20-%20OOP%20in%20PHP/README.md) |
| 6 | Practical PHP tools and architecture | [Guide and examples](06%20-%20Practical%20PHP%20Tools%20%26%20Architecture/README.md) |
| 7 | Coding round | [Exercises and tests](07%20-%20Coding%20Round/README.md) |
| 8 | Extra bonus | [Guide and examples](08%20-%20Extra%20Bonus/README.md) |

Part 4 follows the **final 30-question video**, including session lifecycle, password storage, SQL injection, XSS, CSRF, uploads, recovery tokens, security headers and file authorization. Use its README for local XAMPP setup and expected results. The examples are for learning; review and adapt them before building a real application.

Parts 5–8 follow the planned OOP, practical architecture, coding-round and troubleshooting episodes. Their READMEs list the questions, runnable PHP examples, expected outputs and prerequisites. PHP 8.2 is recommended for the newer examples.
